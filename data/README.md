# Datos de la guía del viajero

Objetivo propuesto: series comparables por territorio, enfermedad y semana, con información climática y procedencia. Ver [contratos](../docs/DATOS.md) y [fuentes](../docs/FUENTES.md).

| Directorio | Uso |
| --- | --- |
| `raw/` | Originales y snapshots locales, conservando procedencia |
| `interim/` | Normalización y tablas intermedias |
| `processed/` | Tablas auditadas para análisis e inferencia |
| `sample/` | Catálogo inicial y plantillas; sin resultados inventados |

Los archivos ya versionados del piloto de Piura se mantienen como antecedentes. No existe todavía una base regional integrada. Los directorios locales de datos permanecen excluidos de Git por defecto salvo archivos ya versionados y sus README.
