# Catálogo y plantillas

Estos archivos documentan contratos propuestos. No son salidas de un modelo ni un conjunto epidemiológico regional.

| Archivo | Contenido |
| --- | --- |
| [catalogo_fuentes.csv](catalogo_fuentes.csv) | Fuentes identificadas y estado de revisión; sin afirmar integración |
| [observaciones_epidemiologicas_plantilla.csv](observaciones_epidemiologicas_plantilla.csv) | Solo encabezados del contrato de observaciones |
| [pronosticos_plantilla.csv](pronosticos_plantilla.csv) | Solo encabezados del contrato de estimaciones |
| [itinerario_plantilla.csv](itinerario_plantilla.csv) | Solo encabezados para paradas de un recorrido |

Las muestras futuras con valores deben identificar claramente si son sintéticas o reales y documentar condiciones de redistribución. Ver [contratos](../../docs/DATOS.md).
