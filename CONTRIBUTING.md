# Cómo colaborar

1. Elegir una tarea pequeña y definir cuándo estará terminada.
2. Crear una rama: `feat/descripcion`, `fix/descripcion` o `docs/descripcion`.
3. Implementar el cambio y actualizar la documentación relacionada.
4. Ejecutar las comprobaciones del proyecto una vez definidas las tecnologías.
5. Abrir un pull request indicando propósito, evidencia y pendientes.
6. Revisar antes de integrar a `main`.

## Criterio de terminado

- Se cumplen los criterios de aceptación.
- Se comprueba el caso principal y los errores relevantes.
- No se incluyen secretos ni archivos generados.
- La documentación refleja el comportamiento real.

## Convenciones

Usar nombres descriptivos y commits pequeños, por ejemplo `feat: agregar registro` o `docs: definir alcance`. Organizar el código por funcionalidad cuando el proyecto crezca. No incorporar herramientas sin una necesidad concreta.
