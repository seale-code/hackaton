# Guía de demostración

## Guion sugerido
1. Problema y usuario objetivo.
2. Propuesta de valor.
3. Recorrido por el flujo principal con datos de ejemplo.
4. Resultado y diferenciación.
5. Limitaciones y próximos pasos.

## Antes de presentar
- [ ] Probar desde una instalación limpia.
- [ ] Verificar que no se muestran credenciales ni datos personales.
- [ ] Preparar datos reproducibles.
- [ ] Comprobar enlaces y accesos.
- [ ] Tener capturas o video de respaldo.
