# Roadmap

## 1. Definición
- [ ] Completar problema, usuarios y propuesta de valor.
- [ ] Acordar el MVP y sus criterios de aceptación.
- [ ] Elegir tecnologías y asignar responsables.

## 2. Primera versión
- [ ] Documentar instalación y ejecución.
- [ ] Construir un flujo completo de extremo a extremo.
- [ ] Añadir datos de ejemplo sin información sensible.
- [ ] Cubrir casos principales y errores con pruebas.

## 3. Calidad y entrega
- [ ] Configurar comprobaciones automáticas según las tecnologías elegidas.
- [ ] Revisar accesibilidad y experiencia de uso si hay interfaz.
- [ ] Documentar despliegue y limitaciones conocidas.
- [ ] Ensayar demo y preparar alternativa grabada.

Crear una issue por tarea con objetivo, responsable y criterios de aceptación. Prioridades: P0 imprescindible, P1 importante, P2 opcional.
