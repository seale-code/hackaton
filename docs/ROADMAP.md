# Próximos pasos del piloto

## Completado en esta entrega

- Demo histórica de dengue en cuatro provincias: consulta, gráficos, CSV y fuentes.
- Entorno Python con dependencias directas fijadas y pruebas automatizadas.
- Adaptadores con calendario compartido provisional, revisión de incompatibles y trazabilidad.
