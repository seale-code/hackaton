# Roadmap del MVP de Piura

## 1. Cerrar alcance y viabilidad de datos
- [ ] Inventariar fuentes, acceso, cobertura temporal y territorial.
- [ ] Seleccionar zonas comparables de Piura.
- [ ] Definir objetivo, horizonte y criterios de aceptación con el mentor.
- [ ] Confirmar tecnologías y responsables.

## 2. Construir datos reproducibles
- [ ] Obtener históricos y registrar procedencia/condiciones de uso.
- [ ] Normalizar zonas y semanas; auditar faltantes y duplicados.
- [ ] Construir tabla integrada y rezagos sin información futura.
- [ ] Preparar un ejemplo pequeño para desarrollar el dashboard.

## 3. Evaluar predicción
- [ ] Definir particiones temporales y baseline.
- [ ] Entrenar un modelo candidato y comparar resultados.
- [ ] Documentar errores por zona, limitaciones y calibración si aplica.

## 4. Integrar dashboard y priorización
- [ ] Mostrar históricos, fecha de corte, horizonte y origen de datos.
- [ ] Diferenciar factores globales de explicaciones locales.
- [ ] Validar criterios de prioridad e implementar ranking reproducible.
- [ ] Integrar el flujo completo con datos reales disponibles.

## 5. Preparar entrega
- [ ] Añadir dependencias, comandos y comprobaciones automáticas reales.
- [ ] Verificar ejecución limpia y casos de datos faltantes.
- [ ] Guardar evidencia, ensayar demo y preparar respaldo.

Las tareas anteriores están pendientes; la estructura del repositorio está lista. Crear issues pequeñas con criterios de aceptación y responsables acordados.
