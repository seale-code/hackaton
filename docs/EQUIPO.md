# Distribución propuesta del trabajo

Plan de cinco frentes basado en las conversaciones; confirmar responsables y carga con el equipo.

| Frente | Entregable |
| --- | --- |
| Informática — datos | Fuentes documentadas, limpieza y tabla zona/semana |
| Informática — ML | Baseline, modelo y evaluación temporal reproducible |
| Informática — integración | Flujo de datos a resultados, contratos y ejecución reproducible |
| Informática — dashboard | Visualización de riesgo, tendencias, factores y ranking |
| Ingeniería Industrial | Criterios de prioridad, restricciones, indicadores y proceso de decisión |

Todos participan en revisión, documentación y demo. No se asignan personas automáticamente desde este documento.
