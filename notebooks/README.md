# Notebooks exploratorios

Los notebooks existentes proceden del piloto de dengue y clima en Piura. Incluyen descargas, integración, regresión exploratoria e índices de El Niño. Se conservan como antecedentes; sus rutas, calendarios y evaluación necesitan revisión antes de reutilizarse.

Ver [inventario y límites](../docs/ANTECEDENTES.md). No hay un notebook regional validado para viajeros.

Para los futuros experimentos, registrar fuente y versión, tarea, corte, particiones temporales, baseline y métricas por territorio/enfermedad. Convertir las transformaciones reutilizables a módulos de `src/` cuando se implementen, sin presentar un ensayo aleatorio como validación temporal.
